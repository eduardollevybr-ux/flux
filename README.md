# FLUX

Aplicativo web de previsão financeira pessoal. Ele projeta o saldo dia a dia ao longo dos próximos 12 meses, considerando entradas, saídas, gastos diários, economias e fatura do cartão, para mostrar com antecedência como o dinheiro vai se comportar em cada data.

## O que o app faz

Mostra uma tabela de saldos diários por mês, com o total de cada categoria e o saldo acumulado. Permite cadastrar lançamentos, inclusive parcelados, buscar lançamentos já feitos e consultar os totais do período.

## Como foi construído

HTML, CSS e JavaScript em uma aplicação de página única. Os dados ficam sincronizados na nuvem com o Supabase. É um PWA: pode ser instalado no celular ou no computador como um aplicativo e tem service worker para carregar mais rápido. A publicação é feita pelo GitHub Pages.

Projeto desenvolvido por Eduardo Levy com apoio de ferramentas de IA generativa.

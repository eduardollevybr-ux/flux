API do FLUX

Ligue seu site, seu sistema de vendas ou sua planilha ao FLUX. Cada venda ou recebimento entra no FLUX sozinho, e você consulta o saldo de qualquer dia sem abrir o app.

Em 5 minutos

  1. No app do FLUX, abra menu > conexões, toque em criar chave, dê um nome (exemplo: "site da loja") e escolha ver e lançar.
  2. Copie a chave. Ela aparece uma única vez e começa com flux_live_.
  3. Mande o primeiro lançamento:
curl -X POST https://ccxiuaqirickchmrowrz.supabase.co/functions/v1/api/v1/lancamentos \
  -H "Authorization: Bearer flux_live_SUA_CHAVE" \
  -H "Content-Type: application/json" \
  -d '{"tipo": "entrada", "valor": 30.00, "descricao": "venda balcão"}'
const resposta = await fetch("https://ccxiuaqirickchmrowrz.supabase.co/functions/v1/api/v1/lancamentos", {
  method: "POST",
  headers: {
    Authorization: "Bearer flux_live_SUA_CHAVE",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ tipo: "entrada", valor: 30.00, descricao: "venda balcão" }),
});
console.log(await resposta.json());
import requests

r = requests.post(
    "https://ccxiuaqirickchmrowrz.supabase.co/functions/v1/api/v1/lancamentos",
    headers={"Authorization": "Bearer flux_live_SUA_CHAVE"},
    json={"tipo": "entrada", "valor": 30.00, "descricao": "venda balcão"},
)
print(r.json())

Pronto: a venda aparece no FLUX no dia de hoje. Se o app estiver aberto, ela aparece quando você voltar para ele.

A chave

Toda chamada leva a chave no cabeçalho Authorization, no formato Bearer flux_live_.... O endereço base de todas as chamadas é:

https://ccxiuaqirickchmrowrz.supabase.co/functions/v1/api
quando criada comoa chave pode
ver e lançarconsultar saldo e lançamentos, lançar e apagar o que entrou pela API
só verconsultar saldo e lançamentos

O FLUX não guarda a chave, só um resumo dela para conferir. Se perder a chave, apague e crie outra. Se apagar uma chave em conexões, ela para de funcionar na mesma hora.

Tipos de lançamento

tipoo que é no FLUX
entradadinheiro que entra: venda, salário, mensalidade recebida
saidacontas e gastos planejados: aluguel, fornecedor, internet
diariogastos pequenos do dia a dia: lanche, padaria, transporte
economiadinheiro guardado
cartaocompra no cartão de crédito; sai do saldo no dia da compra

Conferir a chave

GET/v1/conta

Mostra o nome da chave e o que ela pode fazer. Bom para testar se a chave foi colada certo.

{ "chave": "site da loja", "pode": "ver e lançar" }

Saldo de um dia

GET/v1/saldo?data=AAAA-MM-DD

O mesmo saldo que aparece no app para aquele dia. Sem data, vale hoje (horário de Brasília). Dias futuros já descontam a previsão de diário, como no app.

{ "data": "2026-12-20", "saldo": 1250.4, "previsao_de_diario_por_dia": 35 }

Saldo dia a dia

GET/v1/previsao?de=AAAA-MM-DD&ate=AAAA-MM-DD

O saldo de cada dia do período, com o que entra e sai em cada um e o dia de menor saldo. Sem datas, vai de hoje até 30 dias depois. No máximo 400 dias por vez.

{
  "de": "2026-11-17", "ate": "2026-12-17",
  "menor_saldo": { "data": "2026-12-17", "saldo": -53.93 },
  "previsao_de_diario_por_dia": 0,
  "dias": [
    { "data": "2026-11-17", "saldo": 0, "entrada": 0, "saida": 0, "diario": 0, "economia": 0, "cartao": 0, "previsao_de_diario": 0 }
  ]
}

Listar lançamentos

GET/v1/lancamentos?de=&ate=&tipo=

Os lançamentos como foram cadastrados, do mais novo para o mais antigo, até 500 por vez. Os três filtros são opcionais. Um lançamento que se repete aparece uma vez, com "repete": true e a data da primeira vez.

{ "lancamentos": [
  { "id": "tmwl429hlflxxoe", "tipo": "diario", "descricao": "padaria", "valor": 12.5,
    "data": "2026-11-17", "cartao": null, "repete": false, "origem": "api", "id_externo": null }
] }

origem diz de onde veio: app para o que foi lançado no FLUX, api para o que entrou por aqui.

Lançar

POST/v1/lancamentos
campocomo enviar
tipoobrigatórioentrada, saida, diario, economia ou cartao
valorobrigatórionúmero maior que zero; aceita 30.5, "30,50" e "R$ 1.234,56"
dataopcionalAAAA-MM-DD; sem data, vale hoje
descricaoopcionalaté 80 letras; sem descrição, vira o nome do tipo
cartaoopcionalnome do cartão como está no FLUX; no tipo cartao sem esse campo, usa o cartão padrão
id_externorecomendadoo código da venda ou cobrança no seu sistema; se o mesmo código chegar de novo, o FLUX não lança duas vezes

Resposta 201 com o lançamento criado. Se o id_externo já existia, a resposta é 200 com o lançamento de antes e "repetido": true.

Apagar

DELETE/v1/lancamentos/{id}

Apaga um lançamento que entrou pela API (por exemplo, uma venda cancelada). O que foi lançado no próprio app não pode ser apagado por aqui.

{ "apagado": "tmwl429hlflxxoe" }

Conectar uma IA

Assistentes de IA, como o Claude, conversam com o FLUX por este endereço (servidor MCP):

https://ccxiuaqirickchmrowrz.supabase.co/functions/v1/mcp

No Claude

  1. Abra Settings > Connectors e toque em Add custom connector.
  2. Cole o endereço acima e toque em Add, depois em Connect.
  3. Entre com sua conta do FLUX e toque em autorizar.

Pronto: dá para escrever "hoje gastei R$ 50 em doces" ou perguntar "meu saldo chega até o dia 20?". Para desconectar, abra menu > conexões no FLUX, toque no assistente e segure desconectar.

Em automações e assistentes que aceitam cabeçalho

Ferramentas que não fazem login, como Claude Code ou n8n, usam o mesmo endereço com uma chave criada em conexões, no cabeçalho Authorization: Bearer flux_live_.... Uma chave "só ver" consulta, mas não lança.

No Codex (OpenAI)

O Codex usa o mesmo endereço com uma chave. A chave fica guardada numa variável do computador, e o Codex lê dali, sem gravar a chave no arquivo de configuração. No Mac ou Linux, no terminal:

export FLUX_CHAVE="flux_live_SUA_CHAVE"
codex mcp add flux --url https://ccxiuaqirickchmrowrz.supabase.co/functions/v1/mcp --bearer-token-env-var FLUX_CHAVE

No Windows, no PowerShell, rode a primeira linha, feche e abra o terminal de novo, e rode a segunda:

setx FLUX_CHAVE "flux_live_SUA_CHAVE"
codex mcp add flux --url https://ccxiuaqirickchmrowrz.supabase.co/functions/v1/mcp --bearer-token-env-var FLUX_CHAVE

Dentro do Codex, /mcp mostra se o FLUX está conectado. A variável precisa existir sempre que o Codex abrir; no Mac ou Linux, coloque a linha do export no arquivo de início do terminal (como ~/.zshrc) para não precisar repetir.

O que a IA pode fazer

açãoo que faz
registrar_lancamentoanota um gasto ou recebimento
listar_lancamentosbusca lançamentos por período, tipo ou descrição
consultar_saldosaldo de um dia, igual ao do app

Na prática: vendas de uma loja

A cada venda fechada, o sistema da loja manda uma entrada com o número da venda em id_externo. Se a internet cair e o sistema reenviar, o FLUX reconhece o número e não duplica.

async function enviarVendaAoFlux(venda) {
  await fetch("https://ccxiuaqirickchmrowrz.supabase.co/functions/v1/api/v1/lancamentos", {
    method: "POST",
    headers: { Authorization: `Bearer ${process.env.FLUX_CHAVE}`, "Content-Type": "application/json" },
    body: JSON.stringify({ tipo: "entrada", valor: venda.total, descricao: `venda ${venda.numero}`, id_externo: `venda-${venda.numero}` }),
  });
}
Guarde a chave numa variável de ambiente do servidor (como FLUX_CHAVE acima), nunca no código da página que o comprador abre no navegador.

Na prática: mensalidades de clientes

Quando uma mensalidade é paga, o sistema de cobranças manda a entrada com a data do pagamento. Antes de cobrar algo grande, dá para conferir se o saldo aguenta até o fim do mês:

import requests
BASE = "https://ccxiuaqirickchmrowrz.supabase.co/functions/v1/api"
H = {"Authorization": "Bearer flux_live_SUA_CHAVE"}

# mensalidade paga
requests.post(f"{BASE}/v1/lancamentos", headers=H, json={
    "tipo": "entrada", "valor": "450,00", "data": "2026-11-05",
    "descricao": "mensalidade ana", "id_externo": "cobranca-1189",
})

# menor saldo dos próximos 30 dias
p = requests.get(f"{BASE}/v1/previsao", headers=H).json()
print(p["menor_saldo"])

Erros

Todo erro vem no mesmo formato: { "erro": { "codigo": "...", "mensagem": "..." } }.

situaçãocódigoo que fazer
401sem_chave, chave_invalidaconfira o cabeçalho; se a chave foi apagada, crie outra
403so_vera chave é "só ver"; crie uma com "ver e lançar"
400tipo_invalido, valor_invalido, data_invalida, cartao_nao_encontrado, cartao_obrigatorio, periodo_longocorrija o campo citado na mensagem
404nao_encontradocaminho errado, ou lançamento que não entrou pela API
500falhatente de novo em instantes

Limites

listar lançamentosaté 500 por chamada
saldo dia a diaaté 400 dias por chamada, no máximo 5 anos à frente
descriçãoaté 80 letras
datassempre AAAA-MM-DD, no horário de Brasília
